# Dr. Abel U. Osagie — Portfolio

## Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Routing:** React Router v6
- **Package Manager:** pnpm

## Prerequisites

- Node.js >= 22
- pnpm

## Run Locally

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
